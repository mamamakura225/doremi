# どれみ — 要件定義

**何を作るか**を定める。設計理由は [architecture.md](./architecture.md)。

## 背景と価値
5歳児は耳では「ドレミ」を歌えても、それが五線譜のどこにあるかは結びついていない。**音を鳴らしながら音符を置く**ことで、耳で覚えた音高と譜面上の位置を対応づける。楽譜を読ませるのではなく、置いて鳴らして遊ぶうちに位置が身につくことを狙う。

## ターゲットと利用環境
- 対象: 5歳前後（ひらがなが読めはじめる頃）。文字は最小限、操作は指1本で完結させる
- 端末: スマホ／タブレット、**横向き前提**
- 本番: https://doremi.vercel.app （public・誰でもアクセス可）
- バックエンド・認証・外部APIを持たない**純クライアント**。子どものデータは端末外に出ない

## MVP スコープ（実装済み）

### 譜面と音符
- ト音記号の五線譜（デフォルトかつ現状唯一のモード）
- 音域は **C4（真ん中のド・下加線1本）〜 E5** の1オクターブ+α
- お道具箱から音符をドラッグして五線譜に置く。置いた音符は上下ドラッグで音高変更、下部のゴミ箱ゾーンへドラッグで削除
- ドラッグ中は音高ゾーンを跨いだ瞬間に音が鳴る（スクラブ発音）
- 真ん中のドの位置に**半透明の足場ガイド**を常時表示
- 符頭をドレミの色相で塗り分け（ド=赤／レ=橙／ミ=黄／ファ=緑／ソ=水色／ラ=紫／シ=桃）

### ページ（フレーズ）
- **1ページ10音**が上限
- 満杯になったら「つぎのうた」で空ページを追加。複数ページを連結して再生（ページ境界に1ステップの小休符）

### 再生
- 左から順に等間隔（600ms/音）で再生し、鳴っている音符をハイライト
- 再生音色を4種から選択: 🎹ぴあの／🔔べる／🎵ぴこぴこ／🎤うた（ドレミ）
- 「うた」は楽器音に**重ねて**音名を読み上げる（Web Speech API）
- 全音の再生完了でお祝い演出（符頭バウンス・1.4秒）

### おてほん
- 「きらきらぼし」第1フレーズ（ド ド ソ ソ ラ ラ ソ＝7音）をガイド表示するモード
- じゆうモードと切り替え。一致したときは控えめなキラキラ音

### 保存
- つくった曲を localStorage の「ほんだな」に保存（最大12曲・古いものから落ちる）

### 画面
- PWA（ホーム画面追加・オフライン動作・`orientation: landscape` / `display: fullscreen` 宣言）
- 縦向き検知で「回してね」オーバーレイ

## スコープ外（見送った／やらない）
| 項目 | 理由 |
|---|---|
| **リズム（音の長さ）** | 位置の習得を優先。導入するなら長短2値から（[#43](https://github.com/mamamakura225/doremi/issues/43)） |
| **ヘ音記号モード** | ト音を先に完成させる方針。音域 F2〜G3・温かい音色で後追い追加（[#6](https://github.com/mamamakura225/doremi/issues/6)） |
| **1ページ11音以上** | 横向きスマホで符頭が接し、掴み分けられなくなる（列間隔の下限 ≧65・ビューボックス単位） |
| **鍵盤の併記** | 家庭学習との接続として検討中（[#30](https://github.com/mamamakura225/doremi/issues/30)） |
| **♯♭・臨時記号・調号** | 対象年齢に対して概念が早い |
| **アカウント・クラウド保存・共有** | 純クライアントを崩さない。子どものデータを端末外に出さない |
| **キャラクター演出の作り込み** | お祝いは符頭バウンスの最小演出に留める |

## 制約
- **横向きは技術的に強制できない**（iOS Safari 等で `orientation.lock` 不可）。オーバーレイで誘導するしかない
- **音はユーザー操作なしに出せない**（AudioContext）。初回タップまで無音なのは仕様
- Web Speech API の ja-JP 音声は端末依存で、ネットワーク音声の端末では機内モード時に読み上げが出ない。うたモードは楽器音に重ねているため無音にはならない
- 純クライアントのため、テストできるのは `src/lib` の純ロジックと UI のみ
