# どれみ — 要件定義

**何を作るか**を定める。設計理由は [architecture.md](./architecture.md)。

## 背景と価値
5歳児は耳では「ドレミ」を歌えても、それが五線譜のどこにあるかは結びついていない。**音を鳴らしながら音符を置く**ことで、耳で覚えた音高と譜面上の位置を対応づける。楽譜を読ませるのではなく、置いて鳴らして遊ぶうちに位置が身につくことを狙う。

## ターゲットと利用環境
- 対象: 5歳前後（ひらがなが読めはじめる頃）。文字は最小限、操作は指1本で完結させる
- 端末: スマホ／タブレット、**横向き前提**
- 本番: https://doremi-xi.vercel.app （public・誰でもアクセス可）
- バックエンド・認証・外部APIを持たない**純クライアント**。子どものデータは端末外に出ない

## MVP スコープ（実装済み）

### 譜面と音符
- 音部記号を2モードから選ぶ（デフォルト=ト音）。切替はおとなメニューの「ことり／くま」（それぞれの絵のアイコン）
  - **ト音**: 音域 **C4（真ん中のド・下加線1本）〜 E5**
  - **ヘ音**: 音域 **F2（五線の下の間）〜 A3（最上線）**。ドは五線の中にあり加線が要らない。地の音色が低くて温かい音（クマ・ゾウ）に変わる
- どちらも10音・ドレミの並びは同じなので、おてほんも同じ「ドドソソララソ」で成立する
- 音の長さは**ふつう／のばす の2値**。お道具箱に2つの音符が常駐し、のばす音は譜面で2列ぶんを占め、再生では2倍の長さ鳴る（符頭から右へ「のばしバー」が伸びる）
- お道具箱から音符をドラッグして五線譜に置く。置いた音符は下部のゴミ箱ゾーンへドラッグで削除（**音高の直接修正は未実装**——間違えたら捨てて置き直す）
- 置いた音符を**動かさずにタップすると、その音が鳴って符頭がぷるんと揺れる**（捨てない・音高も変えない・#108）。少し動かしてから（指のぶれより大きく）初めて「掴んだ」ことになり、ゴミ箱が出る
- ドラッグ中は音高ゾーンを跨いだ瞬間に音が鳴る（スクラブ発音）
- 真ん中のドの位置に**半透明の足場ガイド**を常時表示
- 各音の高さに音名（ドレミ）を薄く常時表示する（音高色と連動・低音ほど大きい）。置く前の手がかりになる
- 符尾（符幹）は記譜の慣習どおり、**第3線とそれより上の音は下向き（符頭の左）・それより下は上向き（符頭の右）**。レッスンの楽譜と見た目を揃える（#97）。お道具箱の音符は上向き
- 符頭をドレミの色相で塗り分け（ド=赤／レ=橙／ミ=黄／ファ=緑／ソ=水色／ラ=紫／シ=桃）
  - 符頭・ドレミラベルには五線と同色（`#5b524b`）の輪郭を入れる。色だけではクリーム地で見えない音があるため（ミ黄は 1.42:1）
  - 符頭は上からのハイライトで「ぷっくり」見せる（形・寸法・当たり判定は変えない・#100）
- 置いた瞬間、符頭が下端を支点に**ぷにっと潰れて戻り**、同じ色と白の**キラ粒**がまわりに散る（0.6秒ほど・音と同時・#100）。動きを減らす設定では出さない
- お道具箱は**木のかご**。中の音符は**ミルクチョコ色**（7色に無い色。置いてから音高の色になる。白っぽいと二分音符に見えるため避ける）

### ページ（フレーズ）
- **1ページ10列**が上限（ふつうの音=1列・のばす音=2列）
- 満杯になったら「つぎのうた」で空ページを追加。複数ページを連結して再生（ページ境界に1ステップの小休符）

### 鍵盤の併記（家庭学習との接続）
- 五線譜の下に鍵盤を併記する。白鍵はその音部記号で置ける10音そのもので、**符頭と同じドレミ色**で塗り分ける。タップするとその音が鳴る（譜面には置かない）
- 黒鍵は本物の鍵盤に見せるための飾りで、押しても鳴らない（♯♭は対象外）
- **縦に余裕のある画面でだけ出す**（タブレット横など）。スマホ横では出さない——出すと五線譜そのものが縮む

### 再生
- 左から順に1列600msで再生し、鳴っている音符をハイライト（のばす音は2列＝1200msぶんの枠を占め、次の音の手前まで鳴り続ける）
- 再生音色を4種から選択: 🎹ぴあの／🔔べる／🎵ぴこぴこ／🎤うた（ドレミ）。「おといろ」ボタン1つで順に切り替わり、選ぶとその音で試聴する
- 再生中は ▶ が ⏹ に変わり、曲を消さずに止められる
- 「うた」は楽器音に**重ねて**音名を読み上げる（Web Speech API）
- 再生中、**ぴぴが鳴っている音符の真上（五線より上）へ渡り歩く**。音が鳴る瞬間に次の列へ移ってぷにっと着地し、のばす音では着地したままゆらゆら揺れる。左から右へ目で追う手がかり（#104）。動きを減らす設定では跳ばずに今の音の上へ移るだけ
- 全音の再生完了でお祝い演出（#103）。符頭がぴょこぴょこ跳ね、ぴぴが右下からばんざいで飛び出し、紙吹雪（淡色と白）が舞い、短いファンファーレが鳴る。強さは3段階で、どれも2秒以内:
  - **小**（1ページの曲・1.4秒）／**大**（複数ページを完走・1.8秒・紙吹雪が倍）／**特別**（おてほんどおりに置けた・2.0秒・星が降る）
  - 動きを減らす設定では紙吹雪を出さず、ぴぴは静止（音は鳴る）。演出中も ⏹ で止められ、次の音符を置けばそこで終わる（待たせない）

### おてほん
- 「きらきらぼし」第1フレーズ（ド ド ソ ソ ラ ラ ソ＝7音）をガイド表示するモード。ヘ音では1オクターブ下の同じ並び。ガイドが出るのは**1ページ目のみ**（1フレーズが対象）
- じゆうモードと切り替え。一致したときは控えめなキラキラ音

### 保存
- つくった曲を localStorage の「ほんだな」に保存（最大12曲・古いものから落ちる）。音の長さと音部記号も保存され、読み込むとその音部記号に切り替わって復元される
- ほんだなから曲を選ぶと、復元と同時に再生し、じゆうモードに戻る

### シール帳（#105）
遊んだ証を目に見える形にするごほうび。**「正解したら」ではなく「つくったら・きいたら」でもらえる**。もらうだけで、失うことはない。ランダム（ガチャ）・連続ログインの強制・課金は入れない。

| シール | もらえるとき |
|---|---|
| はじめての おんぷ | 音符をはじめて置いた |
| おんぷを さわった | 置いた音符をタップして鳴らした |
| のばす おと | のばす音を置いた |
| さいごまで きいた | 曲を最後まで聞いた |
| ほんだなに しまった | 曲をほんだなに保存した |
| ほんだなの うた | ほんだなの曲を選んだ（そのまま再生される） |
| くまさんの ひくい おと | ヘ音（くま）で音符を置いた |
| ながい うた | 複数ページの曲を最後まで聞いた |
| にじいろ | ドレミファソラシの7色ぜんぶが入った曲を最後まで聞いた |
| おてほん できた | おてほんどおりに置いて最後まで聞いた |

- もらったら、ヘッダーの右寄り（⚙ の左）に「シール ゲット！」のお知らせ（2秒・「ぴんぽん」の音）。何枚か同時にもらったら1枚ずつ順番に出す。お祝いの最中はファンファーレと重なるので音は鳴らさない
- シール帳とほんだなは同時には開かない（片方を開くともう片方は閉じる・▶ でシール帳は閉じる）
- ヘッダーの ☆ ボタンでシール帳を開く。まだのシールは「？」で、全部で何枚あるかが見える
- 保存は端末内（localStorage）。保存できない環境でも、そのとき遊んでいる間はもらえる

### 画面
- アイコンはすべて自前の SVG（ことり・くま・ぴあの・べる・ゲーム機・歌うぴぴ・指・ゴミ箱など）。絵文字は使わない（OS ごとに絵柄が変わるため・#101）
- 世界観は「おんぷのもり」（[art-direction.md](./art-direction.md)）。**五線は原っぱに広げた紙**に載り、紙の外には空・雲・太陽・丘・白い花の背景が見える。雲はゆっくり流れる（動きを減らす設定では止まる・#99）
- PWA（ホーム画面追加・オフライン動作・`orientation: landscape` / `display: fullscreen` 宣言）。Android Chrome のインストール要件を満たすアイコン（192/512 PNG＋maskable）と iOS 用 `apple-touch-icon` を持つ
- 縦向き検知で「よこむきに してね」オーバーレイ
- ヘッダーは**子どもの面**（▶ さいせい・おといろ・↩ ひとつもどる・💾 ほぞん・📚 ほんだな の大きな丸ボタン。アイコンだけ・押すと沈み、↩💾📚 は「ぽこっ」と鳴る）と、**おとなメニュー**（⚙ を 1.5 秒ながおしで開く: ぜんぶけす・ことり／くま・じゆう／おてほん）に分ける（#102）。縦が短い画面（横向きスマホ）では丸を小さくして五線譜に高さを譲る
- 未操作時のみ起動ヒント（指アイコン＋「さわってね」）を出し、初回タップで消える（＝そのタップが AudioContext の解錠も兼ねる）
- 予期しない不具合でも白画面にはせず、🌀 と「もういちど」（リロード）だけの画面を出す

## スコープ外（見送った／やらない）
| 項目 | 理由 |
|---|---|
| **拍・小節・音符の種類（四分／八分…）** | 長さは「ふつう／のばす」の2値だけ持つ。記譜の正しさは追わない |
| **♯♭・臨時記号・調号・移調・ハ音記号** | 対象年齢に対して概念が早い |
| **1ページ11音以上** | 横向きスマホで符頭が接し、掴み分けられなくなる（列間隔の下限 ≧65・ビューボックス単位） |
| **スマホ横での鍵盤併記** | 五線譜が縮む（[#30](https://github.com/mamamakura225/doremi/issues/30) の実測） |
| **鍵盤から音符を置く操作** | 音符はお道具箱から置く1通りに保つ。鍵盤は音を確かめる場所 |
| **置いた音符の音高を直接修正** | タップと掴みは動いた距離で区別できる（#108）が、タップは鳴らすだけに留める。鳴らすつもりで音が変わると混乱する。間違えたら捨てて置き直す |
| **アカウント・クラウド保存・共有** | 純クライアントを崩さない。子どものデータを端末外に出さない |
| **ステージ（五線の紙）の上の常駐キャラ・飾り** | 位置の読みを邪魔する。マスコットは再生中だけ紙の上を渡り歩く。キャラクター演出そのものはスコープ内（2026-09-28 オーナー決定・[#96](https://github.com/mamamakura225/doremi/issues/96)）で、線引きは [art-direction.md](./art-direction.md) |

## 制約
- **横向きは技術的に強制できない**（iOS Safari 等で `orientation.lock` 不可）。オーバーレイで誘導するしかない
- **音はユーザー操作なしに出せない**（AudioContext）。初回タップまで無音なのは仕様
- Web Speech API の ja-JP 音声は端末依存で、ネットワーク音声の端末では機内モード時に読み上げが出ない。うたモードは楽器音に重ねているため無音にはならない
- 純クライアントのため、テストは `src/lib` の純ロジック（カバレッジ閾値あり）＋ UI 層は「実在したバグを捕まえる最小セット」（`src/components/*.test.tsx`・`src/App.test.tsx`・`src/audio/*.test.ts`）。実ビューポートや `setPointerCapture` が要る3経路は Playwright（別issue）。網羅は追わない
