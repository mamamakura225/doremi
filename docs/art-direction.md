# どれみ — アートディレクション

絵の約束事を1枚にまとめる。背景・音符・アイコン・マスコット・演出の各issue（親 [#113](https://github.com/mamamakura225/doremi/issues/113)）は、ここに従って作る。何を作るかは [requirements.md](./requirements.md)、実装上の理由は [architecture.md](./architecture.md)。

見本: [`art/moodboard.svg`](../art/moodboard.svg)（タブレット横 1024×768 の1画面・盤面は実物の座標）・[`art/mascot.svg`](../art/mascot.svg)（マスコットの表情4種）。dev サーバで `/art/moodboard.svg` を開くと見られる。

## 目標
**5歳の女の子が「さわりたい」と思う、やわらかくて上質な画面**。ただし、このアプリの学習価値は「音の高さ＝五線の位置」なので、**五線と符頭の位置が読めることを絵より優先する**（ピアノ講師ペルソナの条件）。

## 世界観: 「おんぷのもり」
森のひらけた原っぱで開く、小さな音楽会。**五線譜は、原っぱに広げた紙（ステージ）**。

| 候補 | 判断 |
|---|---|
| **おんぷのもり（採用）** | 空と丘で画面の余白を自然に埋められ、五線の紙を「舞台」にしやすい。明るい昼の色で、ドレミの7色とぶつからない |
| おかしのくに | 可愛いが、背景の模様（クリーム・トッピング）が細かくなりやすく、五線の周りがうるさくなる。音符が食べ物に見えて「位置」より「絵」を覚えてしまうおそれ |
| よぞらのほし | 暗い地だと、輪郭色（`#5b524b`）とドレミの暗い色（ド赤・ラ紫）が沈む。パレットを作り直すことになる。季節テーマ（[#111](https://github.com/mamamakura225/doremi/issues/111)）の1つとして後で足す |

## 画面の層（どこに何を描くか）
盤面は SVG（viewBox 1100×500、鍵盤を出す画面は 1100×620・`preserveAspectRatio="xMidYMid meet"`）。端末の縦横比で**余白の出方が変わる**——スマホ横では左右に、タブレット横では下に帯が出る。どの端末でも絵が破綻しないよう、次の2層に分ける。

1. **ページ背景（HTML 側・盤面 SVG の外）**: 空・雲・太陽・丘・花。ヘッダーの後ろと、盤面の周りの帯に見える。端末によって見える範囲が変わる前提で、主役を置かない（切れても困らない飾りだけ）
2. **盤面 SVG の中**:
   - **紙（ステージ）**: 五線（y140〜340）・ドの足場ガイド（ト音 y390／ヘ音は五線の中）・掴んだときだけ出るゴミ箱アイコンを載せる（紙は y16〜492）。**不透明**の `#fffdf5`。紙の四隅を留めるテープは、五線から離れた角に限って紙の上に置いてよい（禁則1の例外）
   - **木のかご（お道具箱・x940〜1060）**
   - **鍵盤（y500〜620・出す画面だけ）**
   - それ以外の viewBox 内は透明にして、ページ背景を透かす

配置は viewBox の上端（y≥0）から受け付ける（`isOverPlacement`）ので、viewBox 内に空の絵を描かない。

## マスコット: ひよこの「ぴぴ」
- まんまるの体・大きめの目・ほっぺ・リボン。対象の女の子が「自分の子」と思える要素としてリボンを付けた
- 表情は4種で足りるようにする: **ふつう／にっこり／びっくり／ばんざい**。新しい演出で表情が足りないときは、まずこの4種の組み合わせと動きで表現する
- 1体は 200×200 の座標で描く。塗り: 体 `#ffe38f`（放射グラデーション `#fff6cf`→`#ffd166`）・羽 `#ffd166`・くちばしと足 `#ffa94d`・ほっぺ `#ff8fab`（不透明度 0.6）・**リボン `#ffc9dc`（淡い桃）**
- **ドレミ7色そのものは使わない**。再生中に紙の上を渡り歩く（[#104](https://github.com/mamamakura225/doremi/issues/104)）ので、体の一部が符頭の色と同じだと音符と読み違える。体の黄・リボンの桃は、ミ `#facc15`・シ `#f472b6` より明度を上げて別物に見せている
- 出番: お祝い（[#103](https://github.com/mamamakura225/doremi/issues/103)）・再生中の案内（[#104](https://github.com/mamamakura225/doremi/issues/104)）・空の本棚（[#109](https://github.com/mamamakura225/doremi/issues/109)）・タイトル（[#112](https://github.com/mamamakura225/doremi/issues/112)）。ふだんは紙の外（丘の上など）にいる
- 紙の上に出るときは: **符頭・五線・ドレミラベルを隠さない**。符頭より大きく描く（高さ 2 倍以上）と五線1間ぶん（50）を超えるので、置き場所は**五線の上の余白（最上線 y140 より上）**に限り、鳴っている音の列の真上を渡り歩く
- ことり🐤／くま🐻（音部記号の切替）は、アイコン（[#101](https://github.com/mamamakura225/doremi/issues/101)）で同じ線・塗りの規則に揃える。くまは2体目のマスコットにしない（描く量が倍になる割に、ヘ音で遊ぶ時間は短い）

## パレット
**正はドレミ7色（`src/lib/colors.ts` の `SOLFA_COLOR`）**。7色は「音の高さ」を表すものにだけ使う。

| 役割 | 色 | 備考 |
|---|---|---|
| 音の高さ | `SOLFA_COLOR` の7色 | 符頭・ドレミラベル・足場ガイド（ドの赤）・鍵盤の色帯。**これ以外の絵に7色を使わない** |
| 輪郭・五線 | `#5b524b`（`OUTLINE_COLOR`） | すべての線画はこの1色。黒は使わない |
| 目 | `#3d3530` | 輪郭よりわずかに濃く、表情を締める |
| 紙（ステージ） | `#fffdf5`（不透明） | 現行の盤面色 `#fdf6e3` より明るくして背景と分ける |
| 空 | `#cdeeff` → `#eaf8ff` → `#fdf6e3` | 上から下へ。下端は盤面色に溶かす |
| 丘 | 遠 `#d6efc8`／近 `#bfe3a8` | 低彩度の緑。ファの緑 `#22c55e` と競らない |
| 花・テープなどの飾り | 白 `#fffdf5`・淡い桃 `#ffe4cc`・淡い緑 `#dff3ea` など | 7色を避けた淡色。鍵盤の色帯の近くに有彩色の飾りを並べない |
| 木（かご・本棚） | 地 `#f3d9ae`／木目 `#e0bd85` | |
| お道具箱の音符 | `#a07e62`（ミルクチョコ） | 色は置いてから決まる。白っぽくすると符尾つきの白玉＝二分音符に見える（#100 で実画面を見てクリームから変更）。桃や黄に寄せるとシ・ミに見える |
| 文字 | `#6b6375` | 現行どおり |

**UI（ヘッダーのボタン）**: 白地＋輪郭色のアイコンが基本。色で意味を持たせず、形とアイコンで示す。主ボタン（さいせい）だけ有彩色を使ってよい——ヘッダーは紙と鍵盤から離れているので、音符と見分けがつく。[#102](https://github.com/mamamakura225/doremi/issues/102) で整理済み: さいせい＝緑・とめる＝文字色 `#6b6375`・ほかは白地（選択中を色で示すボタンはおとなメニューへ移した）。紙の上に出るページ送りも7色を使わない（#101 で「つぎ」をソの水色 → 淡い緑 `#dff3ea`、現在ページの点をレの橙 → 輪郭色に変更）

## 線と塗り
- **線**: 輪郭色 1色・端と角は丸（`stroke-linecap/linejoin="round"`）
  - マスコット: 200 単位あたり 4〜5
  - 盤面: 符頭 2〜2.5・符幹 4・五線 3（viewBox 単位）
  - アイコン: **表示サイズで 2 CSS px 以上**（44px のボタンなら、24 単位のアイコンで 2.5 前後）
- **塗り**: ベタ塗り＋**上からのやわらかいハイライト1つ**＋下へのわずかな沈み。放射グラデーションは中心を左上（`cx≈0.35, cy≈0.3`）に置く
- **影**: 落ち影は輪郭色系の半透明（不透明度 0.12〜0.18）・ぼかしのみ。黒い硬い影は使わない
- 細かい模様・テクスチャ・写真調は使わない（縮小時に濁り、容量も増える）
- 絵文字は使わない。OS ごとに絵柄が変わり、世界観が揃わない。アイコンは `src/components/Icons.tsx`（24×24・線 2 前後・7色を使わない淡色の塗り・既定の大きさは 1em）に足す（[#101](https://github.com/mamamakura225/doremi/issues/101)・`App.test.tsx` が画面の絵文字を検査）
  - 起動ヒントの指は**人差し指（左寄り）だけを立てる**。真ん中の指を立てると別の意味に見える
  - 入れ子の `<svg>` には CSS の transform が効かないので、盤面の中で動かすアイコンは外側の `<g>` にアニメのクラスを付ける
  - おといろの「ぴこぴこ」はゲーム機、「うた」は歌うぴぴ。🎵/🎤 は何の音か伝わらなかった（5歳ペルソナ）

## 可読性の禁則
学習の手がかりが絵に負けないための約束。

1. **紙の上に常駐させてよいのは**、五線・音部記号・ドレミラベル・足場ガイド・音符・おてほんのガイドだけ（例外: 五線から離れた紙の角を留めるテープ）。背景の絵は紙の外
2. **一時的な演出**（置いた瞬間のキラ粒・お祝いの紙吹雪・鍵盤と五線をつなぐ光・再生中のマスコット・再生リング・ゴミ箱）は紙の上に出してよい。条件: **2秒以内に消える（再生中のマスコット・再生リングは再生が終わるまで、ゴミ箱は掴んでいる間）・符頭・五線・ドレミラベルを隠さない・7色の飾りは鳴っている音と同じ色だけ**
3. 輪郭色と地のコントラストは **3:1 以上**（`src/lib/colors.test.ts` の現行の基準）。実測は盤面色 `#fdf6e3` で 7.07:1、紙 `#fffdf5` で 7.49:1。紙を入れる [#99](https://github.com/mamamakura225/doremi/issues/99) で紙の色を `colors.ts` の定数にし、輪郭色との比を **7:1 以上**に引き上げて `colors.test.ts` で固定する。背景テーマ（[#111](https://github.com/mamamakura225/doremi/issues/111)）を足すときも、全テーマの紙の色で同じ基準を通す。7色そのものの地とのコントラストは満たせない（1.5〜4.2:1）ので、視認性は輪郭で確保する（[architecture.md](./architecture.md) の「ドレミ色相連動」）
4. 符頭の形（傾いた楕円・寸法 `NOTE_HEAD_RX/RY`）と当たり判定は、見た目を変えても動かさない
5. **符頭に顔（目）は描かない**（オーナー決定 2026-09-28・[#100](https://github.com/mamamakura225/doremi/issues/100) で目あり／なしの見本を比べたうえで）。音符はキャラクターにせず、「位置と色」で読むものに保つ

## 動き
- 基本は**ふわっ・ぷにっ**（ease-out、200〜500ms）。弾む・潰れて戻るなど、手触りを感じる動き
- 常時動くもの（雲・案内の揺れ）はゆっくり、同時に2つまで。起動ヒント（お道具箱の音符の揺れ＋指）は1組で1つと数える
- お祝い（[#103](https://github.com/mamamakura225/doremi/issues/103)）は段階をつけ、長さは2秒以内。演出中も次の操作をふさぎすぎない
- **動きはすべて `prefers-reduced-motion` で止める**
  - CSS のアニメ・Tailwind の `animate-*`: `src/index.css` の reduced-motion ブロックに足す（`src/motion.test.ts` が検査）
  - **JS で動かすもの**（再生クロックで動くマスコットなど・`requestAnimationFrame`・Web Animations API）: `motion.test.ts` では検出できない。`matchMedia('(prefers-reduced-motion: reduce)')` で分岐し、その issue でテストを足す

## アセット方式と容量予算
**絵はインライン SVG（React コンポーネント）で描く。ラスター画像は当面使わない**（issue 起票時の案は「背景＝WebP」だったが、この文書で変更した。オーナー了承 2026-09-28）。

| 理由 | |
|---|---|
| 解像度 | スマホの高 DPR でもにじまない。ビューポート別に複数サイズを用意しなくてよい |
| 端末ごとの余白 | 上の「画面の層」のとおり、背景は端末によって見える範囲が変わる。ベクターなら HTML の背景として伸縮させても崩れにくい |
| 容量 | 実測: マスコット4表情で gzip 1.4KB、ムードボード1枚（空・雲・丘・花・紙・音符・かご・鍵盤・マスコット）でも数KB。現行 JS は gzip 126.3KB（大半が Tone.js） |
| オフライン | JS に入るので、SW のプリキャッシュに自動で乗る |
| 色の一貫性 | パレットをコードの定数から引ける（背景テーマの切替も色の差し替えで済む） |

- 予算（gzip）: **アート全体で +25KB まで**。目安は 背景 6KB・マスコット 3KB・アイコン1つ 0.8KB
- 測り方: `npm run build` 後に `dist/assets/*.js` を `gzip -9` した合計の増分。基準値は 2026-09-28 時点の **126.3KB**。絵を足す PR は本文に増分を書く
- 不採用: 生成画像（WebP）の背景。絵のタッチは豊かになるが、端末ごとに見える範囲が変わる背景に向かず、ビューポート別のサイズも要り、パレットとの一貫性をコードで保てない
- 写真やイラスト調の質感がどうしても要る箇所が出たら、その issue で理由と容量を書いてから例外にする
